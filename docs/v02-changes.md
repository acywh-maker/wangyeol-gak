# v02 변경 기록

v01(태그 `v01`, 0da0b7c) 이후 바뀐 점을 항목별로 한 줄씩 적는다.

## 준비
- 토큰 생성기(`scripts/build_tokens.py`)가 config.toml에 고정 포트(8510)를 다시 만들던 문제 수정 → 토큰을 다시 빌드해도 배포가 깨지지 않음, 테스트 46개 전부 통과

## S1 입장
- 닉네임·PIN 입력란 높이 40px, 두 필드 사이 간격 10px (토큰 `input-height`, `field-gap` 추가)

## 공통
- 화면 맨 위 여백 약 100 → 48 (전체 적용, 토큰 `page-top`. 30으로 해 보고 너무 붙어서 48). 서재 위쪽에 숨은 쿠키 요소가 만들던 14px 간격도 제거
- 글자 크기 단계 전체 키움 (폰에서 작다는 피드백, 카카오페이지 본문 19 기준, 미리보기 비교 후 승인): 본문 16→19, 기본 UI 14→16, 메타 14~15→16, 배지 12→14(높이 24→28), 소제목 18~20→20~22, 화면 제목 22→24, 큰 제목 28→32, 주요 버튼 16→17. 예외: S2 카드 제목 18 유지, 라이트 모드 버튼 14 유지. 입력칸 글자 14→16
- SVG 아이콘 도입: `Icon/` 폴더 파일을 자동으로 불러와 `ds.icon("이름")`으로 사용, 색은 CSS로 지정

## S2 서재
- 시즌 카드 안 위/아래 여백 20/34 → 20/20 (가운데 정렬)

## 시즌 홈 / S4 회차
- "목표·선물 바꾸기" → "목표·선물 바꾸기 ›" + 탭 높이 44 (누를 수 있는 것처럼 보이게)
- S4 머리: 위 "시즌 제목 · N화" / 아래 "약 N분" → 위 "N화 · 약 N분" / 아래 시즌 제목
- 회차 목록 선물 배지(중간·완결) 앞 ◆ → 🎁
- 주요 버튼(하단 바 전체 + 다 봤어요·선물 확인하기·서재로) 글자 16 미디엄으로 통일

## S5 완료
- "오늘 몫 끝!" → "오늘의 에피소드를 다 봤어요!", "지금까지 끝낸 회차 N개" → "지금까지 N화 끝냈어요"
- "완결 선물까지 N화 남음" + 막대 → "N화만 더 보면 완결(중간) 선물이에요" + 한 화에 한 칸 진행 칸
- 다음 화: "N화는 내일 06:00 도착 · 14시간 후" → "내일 오전 6시에 N화가 도착해요 · 14시간 30분 남음" (분까지, 초 없음)
- 버튼 [지금 열기][서재로] → [서재로][미리 열기]
- 마지막 화를 끝내면 같은 화면이 "시즌 완결!" + "N화를 모두 봤어요" + 다 찬 진행 칸으로 바뀜 (S7 대신 B안)
- 서재 배지·시즌 홈 회차 목록의 남은 시간도 "N시간 N분 남음"으로 통일 ("내일 오전 6시 도착 · 14시간 30분 남음")
- 로컬 저장 파일을 Windows가 잠깐 잠가 저장이 실패하던 문제: 잠깐 기다렸다 다시 저장
- 한글 낱말 중간에서 줄이 바뀌던 문제 수정 (제목, 다음 화 안내)
- S4 "노션에서 원문 보기"는 키우기 전 크기 16 유지

## S6 목표와 선물
- 제목 "선물도 골라봐요!" → "선물도 준비해요" + fantasybook 아이콘(#999)
- 시간 칩 사이 간격 3.5 → 5 (토큰 `pill-gap`)
- 목표 상자: 제목은 시즌 이름만, 메타 줄 "총 N화 · 하루 M분 · N일 뒤 완결"
- "완결 선물 · N화" → "완결하는 날 받을 선물"
- 선물 버튼: 아이콘 + 미디엄 글자("나에게 편지 쓰기", "기프티콘 고르기"), 고르면 메인색으로 바뀜
- 이대로 약속하기: 16 미디엄
- fantasybook 아이콘 높이 24 (폭은 비율대로 34.6), 제목 줄 간격이 벌어지던 문제 해결
- 선물 버튼 아이콘 24 → 20, 글자와 간격 4 → 6 (글자 14에 맞춤)
- 하루 시간 칩에서 "직접 입력" 없앰 (5·10·20·30·60분만)
- 선물 고르기: 커피·디저트 칩 사이 3.5 → 5
- 선물 고르기: 고른 상품은 이미지에 메인색 테두리 2 + 버튼이 메인색으로 바뀜 (전에는 고른 표시 없음)
- 선물 고르기: 이미지를 눌러도 골라지게 카드 전체를 누를 수 있게 함 (상품 버튼은 보이는 그대로)
- 선물 고르기: "확인" 버튼을 본문(높이 35)에서 하단 바(높이 56)로 옮김 — 다른 화면과 같게
- "다음에 정할게요" 탭 영역 높이 35 → 44, 폭 88 → 100 (글자 위치는 그대로)

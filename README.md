# 완결각

> 쌓여 있는 자료를, 기다려지는 다음 화로.

완결각은 웹소설의 연재 구조를 쌓아둔 자료에 옮겨, 매일 한 화씩 완결까지 데려가는 습관 형성 서비스예요.

이름은 '완결 낼 각'에서 왔어요. 끝까지 해내는 성취를 담았어요.

## 이런 분께 맞아요
- 웹소설·웹툰을 매일 기다려 보는 분
- 유튜브 '나중에 볼 동영상', 저장만 해 둔 노트가 쌓여 있는 모든 분

## 완결각이 주는 경험
설렘 → 해냄 → 깊어짐

| 단계 | 느낌 | 완결각에서는 |
| --- | --- | --- |
| 설렘 | 매일 들어오고 싶어요 | 다 본 뒤 처음 오는 저녁 7시 30분에 다음 화가 도착해요. 서재에서 도착까지 남은 시간이 막대로 차올라요. |
| 해냄 | 나와의 약속을 끝냈어요 | 스스로 정한 목표대로 완결하면, 미리 골라 둔 선물과 미래의 나에게 쓴 편지가 도착해요. |
| 깊어짐 | 끝낸 뒤에 남는 게 있어요 | 회차마다 남긴 '오늘의 한 줄'을 완결 리포트로 다시 모아 봐요. |

## 따라 해 보기
1. **입장해요.** 닉네임(2~12자)과 PIN 4자리를 넣으면 시작해요. 처음이면 자동으로 가입돼요.
2. **서재에서 시즌을 골라요.** 노션에 쌓아둔 자료가 시즌 한 편씩 보여요.
3. **목표와 선물을 정해요.** 하루에 쓸 시간(5~60분)을 고르면 몇 화로 완결할지 정해져요.
   중간에 받을 편지와 완결 때 받을 선물(기프티콘 예시·편지)도 미리 정할게요.
4. **매일 한 화씩 봐요.** 다 봤으면 '오늘의 한 줄'을 남겨요. 다음 화는 다 본 뒤 처음 오는 저녁 7시 30분에 도착해요.
   기다리기 어렵다면 미리 열어 볼 수도 있어요.
5. **선물을 받아요.** 약속한 회차에 닿으면 중간 선물이, 마지막 화를 끝내면 완결 선물이 도착해요.
6. **완결 리포트를 봐요.** 10화 이상인 시즌을 완결하면, 그동안 남긴 한 줄을 한눈에 모아 볼 수 있어요.

3일 이상 쉬었다가 돌아와도 괜찮아요. 이어서 볼지, 1화부터 다시 볼지 고를 수 있어요.
